> [!WARNING]
> Nezaručuji úplnost ani správnost materiálů. Otázky, požadavky školy i používané technologie se mohou změnit. Berte tento repozitář jako neoficiální pomůcku, ne jako náhradu výkladu učitele nebo aktuálních školních podkladů.

## Struktura repozitáře

Hlavní část tvoří očíslované složky `1_...` až `25_...`. Každá složka odpovídá jednomu maturitnímu tématu.

Podle konkrétního tématu v ní můžete najít:

- `Teorie.md`: vysvětlení tématu a důležitých pojmů,
- `Priklady.md`: otázky a praktické příklady,
- `Materialy/`: doplňující podklady,
- `Projekty/`: ukázkové programy a řešení.

Další složky:

- `quiz-app/`: experimentální aplikace na procvičování otázek,
- `JSProject/`: starší jednoduchá webová verze kvízu,
- `misc/`: poznámky k průběhu maturity a další materiály,
- `realneOtazky/`: zadání, která byla skutečně zadána u maturity v roce 2026.

Ne všechny otázky mají všechny uvedené soubory a některé materiály se mohou překrývat.

## Jak materiály používat

1. Otevřete složku tématu, které se chcete učit.
2. Začněte souborem `Teorie.md`.
3. Zkuste vlastními slovy odpovědět na otázku uvedenou na začátku.
4. Projděte `Priklady.md` a případné projekty.
5. Nakonec si můžete téma procvičit v kvízu.

Kvíz spustíte takto:

```bash
cd quiz-app
npm install
npm run dev
```

V terminálu se poté zobrazí lokální adresa aplikace.

> [!NOTE]
> Kvíz vznikl spíš jako experiment. Otázky a odpovědi jsou použitelné, správná možnost je ale často zřejmá už z nabízených odpovědí. Hodí se hlavně jako rychlá kontrola základní orientace v tématu, ne jako plnohodnotná příprava nebo ověření hlubšího porozumění.
